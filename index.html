Présentation

Cette page vous explique comment créer un agent Webmaster avec Mistral Vibe, qui vous aidera à créer un site web statique et à l'héberger gratuitement grâce à GitHub et aux GitHub Pages.

Un site statique, c'est quoi ?

Un site statique est un site fait de fichiers figés : des pages HTML préparées à l'avance, servies telles quelles au visiteur. C'est une solution rapide, simple et sécurisée — il n'y a pas grand-chose à pirater — ce qui la rend idéale pour des sites vitrines, des portfolios, etc. En contrepartie, un site statique n'a ni base de données ni code exécuté côté serveur : il ne peut pas gérer la création de comptes utilisateurs ni la publication de contenu dynamique. Chaque modification ou ajout suppose d'éditer puis de republier les fichiers du site — et c'est précisément le rôle de l'agent Webmaster.

GitHub, une plateforme d'hébergement de « dossiers versionnés »

GitHub est une plateforme qui héberge des repositories : des « dossiers versionnés », gérés ici avec un outil appelé Git. L'agent Webmaster a besoin de 2 repositories par site : le premier, la source, contient toutes les informations et contenus bruts destinés au site ; le second héberge le site généré. GitHub Pages sera activé uniquement sur ce second repository, afin de le mettre en ligne.

GitHub Pages, un hébergement gratuit avec ses limites

GitHub Pages est un service gratuit, avec quelques limites : 1 Go de stockage maximum par site et 100 Go de bande passante par mois. À titre d'exemple, ce site pèse moins de 5 Mo (0,005 Go) : la limite de bande passante permet donc un peu plus de 20 000 vues par mois, ce qui est en général largement suffisant pour ce type de site.

GitHub Pages fournit des URL par défaut aux sites hébergés ; vous pourrez aussi définir un nom de domaine personnalisé si vous en possédez un. Ce guide ne traite pas de l'achat d'un nom de domaine.
